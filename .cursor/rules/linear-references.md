# Linear Issue References

Always include the Linear issue ID (e.g., `DJA-165`) in:

- **PR title** — prefix or include naturally (e.g., "DJA-165: Add .cursor/rules for cloud agents")
- **PR body** — cite the issue ID and optionally link to it

This applies to all PRs unless the work has no associated Linear issue.
