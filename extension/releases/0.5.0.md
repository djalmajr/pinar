# Pinar Extension 0.5.0

This is the first extension release published independently from the Pinar app. The ZIP can be loaded unpacked in compatible Chromium browsers without waiting for Chrome Web Store approval.

## Added

- Capture batches that collect annotations from multiple pages and copy one complete prompt bundle when finished.
- Rebindable shortcuts and action-menu commands to open Pinar, start or finish a batch, open the panel, or close a batch without copying.
- System notifications when a user-started batch finishes or fails while no overlay is open.
- Seven-language overlay, action menu, batch status, and agent-handoff instructions.
- Shared delivery preferences for destination, batch copy behavior, handoff detail, language, viewer content, and sensitive URL keys.

## Improved

- Faster screenshots when all pins fit in the current viewport.
- A stable progress bar that reports capture, save, copy, success, and failure without reopening the annotation toolbar.
- Consistent settings rows across the extension and Pinar workspace.
- Pinar.dev naming across the extension action, browser management page, and Store package.

## Fixed

- Batch handoffs now publish Markdown as plain text instead of malformed HTML.
- Copy confirmation remains visible for its complete duration and new sessions no longer inherit stale overlay state.
- Restricted browser pages are treated as unsupported instead of surfacing injection errors.
- Batch cancellation closes the server batch without writing to the clipboard.

## Manual installation

1. Download and extract `pinar-extension-0.5.0.zip`.
2. Open the extension management page in a compatible Chromium browser.
3. Enable developer mode and choose **Load unpacked**.
4. Select the extracted directory containing `manifest.json`.

The Chrome Web Store remains the recommended installation path for automatic browser updates.
