# Pinar Extension 0.5.1

This patch improves annotation reliability and makes capture outcomes clearer while reducing the extension's permissions.

## Improved

- Area pins now remain attached to their selected region when nested page containers scroll.
- Successful captures and completed batches report their outcome directly in the Pinar toolbar.
- Extension settings use the same compact, consistent row structure as the Pinar workspace.
- Capture and batch status messages remain available in all seven supported languages.

## Fixed

- A regression that caused area-pin markers to follow the viewport instead of the annotated region.
- Successful saves now say that annotations were saved instead of only reporting a clipboard copy.
- Batch completion no longer depends on a second command or an open annotation toolbar to show its result.

## Privacy and permissions

- Removed the `notifications` permission. Pinar now displays batch completion and failure feedback inside its own interface instead of using browser system notifications.
