# Pinar Extension 0.5.2

This patch makes the overlay, agent handoff, and Windows install path match the rest of Pinar.

## Improved

- Overlay actions now use the same labels as the rest of the product: Click or drag, Adjust selection, Copy, Mask, and Cancel.
- Pin regions are shown with pins by default. Press `R` to switch between pins only and pins plus regions; the saved crop still includes both.
- Agent handoff text no longer starts with an instruction to implement comments. Pin notes may ask for a change or an explanation.
- On Windows, Options downloads `win-x64-Pinar-Setup.exe` instead of showing an install script.
- The action menu always lists close-batch, matching the shortcuts page even when no batch is running.

## Fixed

- Reopening a capture on a different URL now says the page is not the original capture address.
- The overlay copy chord is shown as one shortcut, like the batch copy chord.
