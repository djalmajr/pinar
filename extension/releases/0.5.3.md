# Pinar Extension 0.5.3

This patch restyles the Account tab, shows only Free, Pro, and Founder, and copies the capture bundle before the screenshot save finishes.

## Improved

- Free installations generate a temporary code in one row of icons, with the countdown under the field.
- Paid accounts show email and plan on the left. Sign out is outline. Manage billing appears only on Pro.
- The one-time plan is only Pinar Founder. Options no longer shows a Lifetime label.
- `Ctrl+Enter`, `Command+Enter`, or `Alt+Enter` copies comments and locators first, while the helper is still saving the screenshot. Progress no longer sits at 80% after the paste is already ready.

## Fixed

- Overlay copy now treats Alt+Enter the same as Ctrl+Enter and Command+Enter.
