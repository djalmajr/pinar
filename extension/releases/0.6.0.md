# Pinar Extension 0.6.0

Capture is now one continuous session across pages. Pin what matters, keep browsing, and finish once to save every page, screenshot, and annotation in one record.

## Added

- Continuous sessions are the default, with no batch mode or capture slots.
- Pin numbering continues across every page in the session.
- Tab opens and closes the live session review; Esc keeps the toolbar hidden.
- The review panel lets you edit comments, inspect the selected element or region and path, preview each pin, and remove it with the title-aligned X.
- Completion notifications confirm whether the final capture succeeded or failed.

## Improved

- The toolbar stays hidden across navigation until the user explicitly opens it again.
- Narrow pages shorten labels before hiding the logo and click-or-drag hint.
- The extension menu follows the selected Pinar language and uses “Complete session” and “Cancel session”.
- Every page is revisited for its own screenshot, locally or remotely, before the session is saved.

## Removed

- Batch slots and the separate batch workflow.
- The saved-session action that reopened a capture on its original page.
- Redundant session counters and optional shortcut configuration.
