# Pinar Extension 0.6.1

Voice comments make it faster to describe visual feedback while keeping every recording under the user's control.

## Added

- Record, cancel, transcribe, or send voice comments directly from the pin composer.
- A compact waveform timeline shows recording progress and the 120-second limit without shifting the page layout.
- The waveform itself keeps moving while Pinar transcribes the recording, making the processing state clear without extra copy.
- Voice availability and disabled-state explanations reflect the active local, BYOK, or Pinar Cloud setup.

## Improved

- Transcriptions are inserted at the text cursor, or appended when no cursor position is available, so existing comments are preserved.
- Completed transcripts are copied to the clipboard before insertion, providing a recovery path if the target field rejects the update.
- Loading feedback now stays with the action being processed, including saving and account-code flows.
- Extension sessions and remote profiles remain isolated by the selected local, staging, or production endpoint.
- Staging authentication and environment detection are more reliable during development and testing.
- Extension labels follow the selected Pinar language more consistently.

## Removed

- Redundant transcription status copy when the waveform already communicates processing.
