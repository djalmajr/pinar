# Pinar Extension 0.6.2

Pinar Cloud now starts with an email account for Free and Pro users. Voice comments and the pin composer also receive the improvements prepared since 0.6.0.

## Added

- Sign in or create a Free cloud account with the one-time code received by email.
- Record, cancel, transcribe, or send voice comments from the pin composer, with a waveform showing progress and the recording limit.

## Improved

- The pin composer moves back inside the window when the pin is near an edge. A long comment scrolls inside the card instead of leaving the screen.
- On Pinar Cloud Free, the microphone says voice comments are available only to Pinar Pro subscribers.
- Extension requests no longer send the website session cookie, so an older site login cannot block remote storage.
- Transcriptions are copied to the clipboard before insertion, providing a recovery path when the target field rejects an update.

## Removed

- Generating a temporary extension code to open Pinar Cloud anonymously. Cloud access now requires email sign-in.
