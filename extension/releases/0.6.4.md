# Pinar Extension 0.6.4

Sign in to Pinar Cloud directly in the Remote Server settings with a code sent to the email address registered on pinar.dev. Create an account on the website first; the extension no longer asks you to accept the Cloud terms again or shows Cloud storage status before sign-in.

The settings now group storage destination, language, and theme under Preferences. Capture contains agent handoff and privacy options. Project and collection destinations are managed in the web app.
