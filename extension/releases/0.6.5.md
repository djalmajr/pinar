# Pinar Extension 0.6.5

- Optionally include the saved viewer's full Markdown in the clipboard handoff, alongside the structured `pinar-visual-context` block. This setting is opt-in and requires the viewer to be included; the compact handoff remains available.
- Cloud account settings now show a loading state while account and subscription details are resolved. Responses from outdated account or trial requests are ignored so stale state does not replace the current account state.
- Session completion feedback now says the session was saved rather than copied.
