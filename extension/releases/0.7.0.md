# Pinar Extension 0.7.0

- The default clipboard handoff is now compact: every useful fact appears once — the CSS selector and DOM path only when they differ, bounded inner text, at most three deduplicated technical-evidence entries with the most relevant first, and geometry only when the pin needs it. The element snapshot stays out of the prompt and remains available through the full context link in the session Markdown.
- Session completion follows the saved copy mode: **Prompt** copies the session handoff text, **Link** copies only its Markdown URL (no Markdown fetch, no credentials embedded), and **Off** leaves the clipboard untouched. The mode is chosen in the extension options and applies to each finished batch.
- Pinar Cloud links stay private: a private Markdown document opens only with your account or an authorized key, and sharing publishes an explicit, unlisted link that anyone with the URL can open. The **Link** completion mode hands over that URL so agents can fetch it with their own access.
- The viewer's pin discussion is now a real comment thread: the original note and the saved thread comments appear together, with a preview that renders the stored pin Markdown and the captured technical evidence. Local workspaces allow editing any saved note or comment; on Pinar Cloud the session owner edits the note, human comments are edited only by their author, and agent comments are never editable in the viewer. Edits keep the message identity, authorship, and timestamps.
- This release is distributed on GitHub, without a Chrome Web Store submission. For manual installation, extract `pinar-extension-0.7.0-unpacked.zip` and select the extracted folder with Chrome's **Load unpacked**. The extension uses Pinar Cloud production by default.
