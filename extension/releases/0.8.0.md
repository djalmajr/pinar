# Pinar Extension 0.8.0

- Voice comments work in local mode. When Pinar Local has an AI provider with a transcription model (Settings → AI), the overlay records the comment and the local server transcribes it; with **Clean up transcription with AI** on, the transcript becomes a comment with acceptance criteria. Without a transcription model, the overlay explains where to configure it. Pinar Cloud voice is unchanged.
- The voice check no longer asks the local server every time the prompt opens: once voice is confirmed available, the extension keeps that answer until a transcription fails because the AI or the local server is unavailable, or until the storage mode changes. The microphone shows the checking state only on the first prompt of a page.
- The options page chooses the capture destination with a single cascading menu: project first, then collection, with search, project icons, and the selected path shown in the field, kept in sync with the server.
- When the sign-in email cannot be delivered, the options page shows a localized message instead of reporting that a code was sent.
- This release is distributed on GitHub. For manual installation, download **`pinar-extension-0.8.0-unpacked.zip`**, extract it, and select the extracted folder with Chrome's **Load unpacked**. Do not load `pinar-extension-0.8.0.zip`: it is the Chrome Web Store upload package, has no extension key, and Pinar Cloud rejects its sign-in requests with "Invalid request origin". The extension uses Pinar Cloud production by default.
