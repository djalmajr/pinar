# Pinar Extension 0.8.1

- In local mode, a voice comment that fails now says why, in the overlay's language: an AI key without permission to transcribe audio, an API key the AI endpoint rejected, a transcription model the endpoint does not offer, or an endpoint that did not answer. Each message points to Pinar Settings → AI. Local voice failures no longer ask you to connect the extension to Pinar Cloud. Pinar Cloud voice messages are unchanged.
- This release is distributed on GitHub. For manual installation, download **`pinar-extension-0.8.1-unpacked.zip`**, extract it, and select the extracted folder with Chrome's **Load unpacked**. Do not load `pinar-extension-0.8.1.zip`: it is the Chrome Web Store upload package, has no extension key, and Pinar Cloud rejects its sign-in requests with "Invalid request origin". The extension uses Pinar Cloud production by default.
