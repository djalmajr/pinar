# Pinar Extension 0.8.2

- On sites that use single-letter keyboard shortcuts (such as x, f, j or k), those letters now reach the Pinar prompt and the review comments instead of triggering the site's shortcut. If a site still cancels a key before Pinar sees it, the typed character, Backspace or Delete is applied to the field anyway, removing whole emoji and accented characters.
- In the review panel, Tab in a comment moves to the next control again and Esc no longer closes the panel.
- This release is distributed on GitHub. For manual installation, download **`pinar-extension-0.8.2-unpacked.zip`**, extract it, and select the extracted folder with Chrome's **Load unpacked**. Do not load `pinar-extension-0.8.2.zip`: it is the Chrome Web Store upload package, has no extension key, and Pinar Cloud rejects its sign-in requests with "Invalid request origin". The extension uses Pinar Cloud production by default.
