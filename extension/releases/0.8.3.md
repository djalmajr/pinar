# Pinar Extension 0.8.3

- When your own AI endpoint fails a voice transcription, the overlay now says why (rejected key, missing model, rate limit with the wait, endpoint that did not answer, or an invalid answer) instead of a generic error, and offers **Use Pinar credits**, which sends the same recording again with your Pinar credits for that request only.
- Cancelling a voice note while it is still being encoded no longer sends it and frees the comment field. A recording kept for **Use Pinar credits** is released when you start a new one or save the comment yourself, and Enter cannot save the comment while a voice note is still pending.
- With **Choose the collection automatically** on in Pinar Cloud (Settings → Capture), the destination field in the extension options reads **Automatic**.
- This release is distributed on GitHub. For manual installation, download **`pinar-extension-0.8.3-unpacked.zip`**, extract it, and select the extracted folder with Chrome's **Load unpacked**. Do not load `pinar-extension-0.8.3.zip`: it is the Chrome Web Store upload package, has no extension key, and Pinar Cloud rejects its sign-in requests with "Invalid request origin". The extension uses Pinar Cloud production by default.
